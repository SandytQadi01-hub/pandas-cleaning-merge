# Pandas — تنظيف ودمج وتلخيص البيانات + مشروع تحليل عملاء

نوتبوك واحد منفّذ بالكامل يغطّي الأجزاء 1-5، مع مشروع تكاملي لتحليل عملاء متجر.
كل الخلايا مُنفّذة والنتائج ظاهرة تحتها.

## الملفات

- **`pandas_cleaning_merge_project.ipynb`** — النوتبوك الكامل (الحلول + المشروع + الخلاصة).
- **`pandas_cleaning_merge_project.html`** — نسخة HTML جاهزة للعرض بالمتصفح مباشرة.

## المحتوى

- **الجزء 1 — القيم المفقودة (Titanic):** عدّها مرتبة، تعويض `age` بالمتوسط في
  عمود `age_filled`، قرار حذف `deck` (77% مفقود) مع التبرير، وتعويض `embarked`
  بالمنوال (Mode) لأنه عمود نصي.
- **الجزء 2 — التكرارات:** جدول عملاء فيه صفوف مكررة عمدًا، اكتشافها بـ
  `duplicated()`، وحذفها بـ `drop_duplicates(keep='first')`.
- **الجزء 3 — GroupBy (Titanic):** متوسط `fare` لكل فئة، نسبة النجاة لكل جنس،
  GroupBy مزدوج (جنس + فئة)، وعدد الركاب لكل ميناء.
- **الجزء 4 — الدمج:** `inner` / `left` / `outer merge` مع شرح الفرق عمليًا
  (تأثير العميل غير الموجود)، و`concat` للصق جداول الطلبات.
- **الجزء 5 — المشروع التكاملي:** بيانات متجر فيها مفقودات + تكرارات، تنظيفها،
  `left merge`، تلخيص عدد الطلبات وإجمالي الصرف لكل عميل، وجدول **Top Customers**.

## أبرز النتائج (متحقّق منها)

- متوسط `fare`: الفئة الأولى الأعلى (84.15).
- أعلى نجاة: إناث/فئة أولى **96.8%** — أدنى: ذكور/فئة ثالثة **13.5%**.
- ميناء الصعود: S=644، C=168، Q=77.
- **أفضل 3 عملاء:** ليان (650) ثم أحمد (500) ثم عمر (400).
- ملاحظة: العميلان نور وهدى بلا أي طلبات (ظهرا فقط بفضل `left merge`).
